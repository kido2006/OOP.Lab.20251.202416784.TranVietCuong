Question:
Programming with AWT and Swing is quite similar (similar elements including container/components, event-handling). However, there are some differences that you need to note:
The top-level containers in Swing and AWT
The class name of components in AWT and corresponding class’s name in Swing

Answer:
Differences in top-level containers:
- AWT: Uses Frame as the top-level container. Components can be added directly to the Frame.
- Swing: Uses JFrame as the top-level container. Components must be added to the ContentPane of the JFrame, not directly to the frame itself.

Differences in component class names:
- AWT components: Use simple class names such as Button, Label, TextField, Frame, etc.
- Swing components: Use corresponding class names with a leading J, for example JButton, JLabel, JTextField, JFrame, and so on.

Question:
The Aims class must be updated to handle any exceptions generated when the play() methods are called. What happens when you don't update for them to catch?

Answer:
When the Aims class is not updated to handle (catch) the exceptions thrown by the play() methods, the following happens:
- The exception propagates up the call stack.
- If it is not caught anywhere, the program terminates at runtime.
- Java prints a stack trace to the console.
- The remaining code after the play() call is not executed.
To prevent this, the Aims class must use try–catch blocks to handle the exception and allow the program to continue running normally.
